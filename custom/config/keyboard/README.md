# Keebwerk Mega ANSI: VIA keymap

A versioned copy of the board's VIA layout. Nix does NOT apply it, layouts live
in the board flash and are imported by hand in the VIA app.

Umlauts (ä ö ü) and `~` are not on the board, karabiner does them, see
`home/gui/karabiner/`.

Nothing is checked in, so the flash is the only copy. To change that, open VIA,
save the layout next to this README and commit it.
